# 회의록 형식

파일명: `meeting_YYYYMMDD_ID.txt` (예: `meeting_20250110_MTG003.txt`)
분석 스크립트는 이 형식의 txt를 읽습니다.

```
회의 ID: MTG003
회의 제목: 고객 피드백 & 성과 평가 논의
날짜: 2025-01-10
시간: 10:00 - 11:30
장소: 회의실 G
회의 유형: 긴급            ← 정기 / 임시 / 긴급 중 하나

2. 참석자 정보
참석자: 이름1, 이름2, 이름3
불참자: 이름1, 이름2       ← 없으면 "없음"

3. 회의 내용
주요 주제: 주제1, 주제2, 주제3
안건별 논의 내용:
  - 주제1: 내용
  - 주제2: 내용

4. 결정사항
  - 결정사항1
  - 결정사항2

5. 후속 조치
  - 액션 아이템1: 내용 - 담당자: 이름 - 마감일: YYYY-MM-DD
  - 액션 아이템2: 내용 - 담당자: 이름 - 마감일: YYYY-MM-DD

6. 다음 회의 정보
  - 예정일: YYYY-MM-DD HH:MM
  - 장소: 장소
```

## 샘플 30건 생성 조건 (책의 프롬프트)

- 참석자 풀: CEO, CTO, 디자인 리드, 마케팅 매니저, QA 리드, 운영 매니저, 재무 담당, 인사 담당, 고객 지원 리드, 연구 개발 리드
- 주제 풀: 제품 개발 로드맵, 마케팅 전략, 예산 계획, 인사 정책, 고객 피드백, 시장 분석, 기술 동향, 팀 빌딩, 성과 평가, 운영 효율화
- 회의마다 참석자 3~7명, 주제 2~4개를 랜덤 선택
- 날짜는 2025-01-01 ~ 2025-04-14 사이 랜덤
- 장소는 회의실 A~G, 온라인, 카페테리아 중 랜덤
- 특정 인물·주제가 더 자주 등장하도록 비중을 다르게 한다 (예: CEO 8회, 재무 담당 3회)

## 클로바노트 txt와의 차이

클로바노트에서 받은 txt는 위 형식이 아니라 발화 기록입니다. 그대로는 분석되지 않으니
`transcripts/raw/`에 넣어 두고, 참석자·주제·결정사항·액션아이템을 정리해 위 형식으로 만든 뒤 `meetings/`에 두세요.
